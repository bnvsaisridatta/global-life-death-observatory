# 🌍 VitalStats — Global Life & Death Observatory

A real-time interactive dashboard tracking global statistics on births,
deaths, homicides, suicides, IVF births, cancer deaths, and more —
spanning 100 years of data (1924–2024).

🔗 **Live demo:**  https://bnvsaisridatta.github.io/global-life-death-observatory/

## Features
- Live ticking counters (updating every 250ms since midnight UTC)
- 100-year historical trend charts (line / bar / area)
- Selectable categories — toggle any metric on/off
- Year-range filter and year-vs-year comparison
- Real-time data from WHO & World Bank free APIs
- Cause-of-death donut breakdown
- Per-second / per-day rate table

## Data Sources (all free, no API key)
- WHO Global Health Observatory API
- World Bank Open Data API
- UN World Population Division
- UNODC Homicide Monitor
- ESHRE ART Fact Sheets
- Our World in Data

## Tech Stack
HTML · CSS · Vanilla JavaScript · Chart.js · GitHub Pages
